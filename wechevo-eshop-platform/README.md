# WeChevo — Πλατφόρμα ενοικίασης e-shop

Πολυ-ενοικιαστική (multi-tenant) πλατφόρμα σε **PHP 8.1+ / SQLite**, χωρίς Composer, npm ή build server.
Μία εγκατάσταση εξυπηρετεί τον πίνακα Super Admin και όλα τα καταστήματα. Κάθε κατάστημα έχει δικό του domain και **δικό του αρχείο βάσης** (`data/shops/{id}.sqlite`).

> Έκδοση: **1.0.0-phase1**. Δείτε στο τέλος τι περιλαμβάνει η φάση 1 και τι μένει.

---

## 1. Απαιτήσεις

| | |
|---|---|
| PHP | 8.1, 8.2 ή 8.3 (δοκιμάστηκε σε 8.3) |
| Extensions | `pdo_sqlite`, `sqlite3`, `mbstring`, `intl`, `gd` (με WebP), `fileinfo`, `xmlreader`, `xmlwriter`, `simplexml`, `curl`, `openssl`, `zip` |
| Server | Apache ή LiteSpeed με `mod_rewrite` (Hostinger shared/cloud) |
| PHP ρυθμίσεις | `upload_max_filesize` ≥ 32M, `post_max_size` ≥ 32M (για εισαγωγές μεγάλων αρχείων), `max_execution_time` 30+ |

Στο Hostinger: **hPanel → Advanced → PHP Configuration** → επιλέξτε PHP 8.3 και ενεργοποιήστε τα παραπάνω extensions (συνήθως είναι ήδη ενεργά).

## 2. Πώς δουλεύουν τα domains

- **Domain πίνακα ελέγχου** (π.χ. `panel.wechevo.gr`): εκεί λειτουργεί το `/superadmin/`.
- **Domain κάθε καταστήματος** (π.χ. `example.gr`): η βιτρίνα και η διαχείρισή του στο `example.gr/admin/`.
- Όλα τα domains πρέπει να δείχνουν **στον ίδιο φάκελο** της εγκατάστασης. Το σύστημα αναγνωρίζει το κατάστημα από το domain του αιτήματος.
- Το `www.` ανακατευθύνεται αυτόματα (301) στο κύριο domain χωρίς `www`.

Στο Hostinger αυτό γίνεται με έναν από τους εξής τρόπους (επαληθεύστε στο πακέτο σας):
1. **Parked / Alias domain** του κύριου site (hPanel → Domains → Parked domains). Δείχνει στον ίδιο `public_html`.
2. **Addon domain** με φάκελο ρίζας τον ίδιο φάκελο της εγκατάστασης (στη δημιουργία, αλλάξτε το προτεινόμενο folder).

Για κάθε domain ενεργοποιήστε **SSL** (hPanel → Security → SSL). Η πλατφόρμα επιβάλλει HTTPS στα καταστήματα (ρύθμιση στο Super Admin).

## 3. Εγκατάσταση (File Manager)

1. **Αντίγραφο ασφαλείας** του υπάρχοντος site, αν υπάρχει. Μην ανεβάσετε ποτέ πάνω από ζωντανό site χωρίς backup.
2. hPanel → **File Manager** → `public_html` (ή ο φάκελος που θα εξυπηρετεί τα domains).
3. Ανεβάστε το `wechevo-site-php.zip` και κάντε **Extract** εκεί.
4. Βεβαιωθείτε ότι οι φάκελοι `data/` και `uploads/` είναι εγγράψιμοι (755/775).
5. Ανοίξτε `https://panel.wechevo.gr/`. Θα εμφανιστεί ο **οδηγός εγκατάστασης** (δεν υπάρχουν προεπιλεγμένοι κωδικοί):
   - όνομα πλατφόρμας, domain πίνακα ελέγχου, email ειδοποιήσεων
   - λογαριασμός Super Admin (κωδικός ≥ 10 χαρακτήρες με γράμματα και αριθμούς)
6. Η βάση δημιουργείται αυτόματα με migrations και αρχικά δεδομένα: πακέτα Starter/Business/Pro, πρότυπα, πάροχοι πληρωμών. Όλα επεξεργάσιμα.

Τοπική δοκιμή: `php -S localhost:8000 index.php`. Για καταστήματα χρησιμοποιήστε domains `*.localhost`, π.χ. `demo.localhost`, που οι browsers λύνουν τοπικά.

### Προστασίες που εφαρμόζονται αυτόματα
- `app/` και `data/` → `Deny` (.htaccess). Οι βάσεις `.sqlite` δεν σερβίρονται ποτέ.
- `uploads/` → **καμία εκτέλεση PHP**, μόνο εικόνες, `nosniff`, CSP sandbox.
- Αρχεία που ξεκινούν με `.` και τα `.md`/`.log` μπλοκάρονται.

## 4. Cron (υποχρεωτικό για λήξεις και ειδοποιήσεις)

hPanel → **Advanced → Cron Jobs** → κάθε 15 λεπτά:

```
/usr/bin/php /home/USER/public_html/cron.php
```

Η ακριβής εντολή και ένα εναλλακτικό URL με κλειδί εμφανίζονται στο **Super Admin → Ρυθμίσεις**. Το cron:
- ενημερώνει καταστάσεις συνδρομών: ACTIVE → EXPIRING (≤10 ημέρες) → EXPIRED → LOCKED μετά τις ημέρες χάριτος (προεπιλογή 3)
- στέλνει ειδοποιήσεις 10 / 3 / 1 ημέρα πριν τη λήξη (μία φορά η καθεμία)
- συνεχίζει εισαγωγές που έμειναν ανοιχτές και ανανεώνει τα XML feeds

Αν το cron λείπει, ο έλεγχος τρέχει και αυτόματα κάθε 10 λεπτά με την κίνηση του site.

## 5. Email

Super Admin → Ρυθμίσεις → Email:
- **PHP mail()**: λειτουργεί στο Hostinger αν το αποστολέας είναι email του ίδιου domain.
- **SMTP** (συνιστάται): `smtp.hostinger.com`, port `465`, χρήστης/κωδικός του mailbox.
- **Καταγραφή σε αρχείο**: για δοκιμές (`data/logs/mail.log`).

Υπάρχει κουμπί αποστολής δοκιμαστικού email.

## 6. Ροή δημιουργίας καταστήματος

Super Admin → **+ Νέο κατάστημα** (οδηγός): Πελάτης → Domain → Πακέτο → Διάρκεια → Πρότυπο → Διαχειριστής → Έλεγχος → Δημιουργία.
Τα στοιχεία σύνδεσης εμφανίζονται μία φορά και, προαιρετικά, στέλνονται με email. Ο πελάτης συνδέεται στο `https://domain/admin/` και ακολουθεί τη λίστα «Ξεκινώντας» του πίνακά του.

Από τη σελίδα του καταστήματος ο Super Admin κάνει:
- **ανανέωση / μηδενισμό χρονομέτρου** (δεν αγγίζει προϊόντα, παραγγελίες, ρυθμίσεις)
- **αλλαγή πακέτου**. Σε υποβάθμιση ζητείται επιβεβαίωση και απενεργοποιούνται τα πιο πρόσφατα ενεργοποιημένα προϊόντα. Δεν διαγράφεται κανένα.
- κλείδωμα, αναστολή, ξεκλείδωμα, domains, πληρωμές, νέο κωδικό χρήστη
- **σύνδεση ως διαχειριστής** (impersonation, καταγράφεται στο audit log)
- διαγραφή σε δύο βήματα (πληκτρολόγηση domain), επαναφορά, οριστική διαγραφή με τελικό backup

## 7. Εισαγωγή προϊόντων

Διαχείριση καταστήματος → **Εισαγωγή / εξαγωγή**:
- CSV (κόμμα, ερωτηματικό ή tab, UTF-8 ή Windows-1253) ή XML (στοιχεία `<product>`/`<item>`, π.χ. μορφή Skroutz).
- Ροή: Ανέβασμα → Έλεγχος → Αντιστοίχιση στηλών → Επιβεβαίωση → Επεξεργασία σε παρτίδες των 250 → Αναφορά.
- Ταύτιση με SKU (ενημέρωση υπαρχόντων), ανίχνευση διπλοτύπων, αναφορά σφαλμάτων ανά γραμμή.
- Ενεργοποίηση: «όλα ανενεργά», «μέχρι το όριο», ή «από στήλη του αρχείου». Πάντα μέσα στο όριο ενεργών.
- Πριν από κάθε εισαγωγή γίνεται αυτόματο backup της βάσης του καταστήματος.
- Αρχεία μεγαλύτερα από το `upload_max_filesize` του server απορρίπτονται με σαφές μήνυμα.

## 8. Αντίγραφα ασφαλείας

- Super Admin → **Αντίγραφα ασφαλείας** → «Αντίγραφο όλων τώρα» (SQLite `VACUUM INTO` στο `data/backups/`) και λήψη.
- Αυτόματα πριν από: υποβάθμιση πακέτου, διαγραφή, οριστική διαγραφή, εισαγωγή.
- Για τις εικόνες κατεβάστε επιπλέον τον φάκελο `uploads/` (File Manager → Compress).
- Συνιστάται και το εβδομαδιαίο backup του Hostinger.

## 9. SEO / Search Console

Κάθε κατάστημα εξυπηρετεί αυτόματα `/sitemap.xml` (με εικόνες), `/robots.txt` (επιτρέπει GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended) και `/llms.txt`.
1. Διαχείριση → **SEO**: τίτλος και περιγραφή αρχικής, GA4 ID (φορτώνεται μόνο μετά από συγκατάθεση cookies), κωδικός επαλήθευσης Search Console.
2. Search Console → Add property → επαλήθευση με meta tag → **Sitemaps** → `https://domain/sitemap.xml`.
3. Κάθε προϊόν έχει δομημένα δεδομένα Product/Offer/BreadcrumbList. Δεν δημιουργούνται ψεύτικες κριτικές.

## 10. Cache (LiteSpeed)

Οι HTML σελίδες έχουν session (καλάθι), άρα **μην** ενεργοποιείτε full-page cache στο LiteSpeed Cache Manager για αυτά τα domains. Τα `assets/` και `uploads/` cache-άρονται από το `.htaccess` (30 ημέρες). Αν ενεργοποιήσετε cache, κάντε «Purge all» μετά από αλλαγές εμφάνισης.

## 11. Δοκιμές

```
php -S 127.0.0.1:8000 index.php        # σε καθαρό αντίγραφο
php tests/acceptance.php               # 108 έλεγχοι: §74–§80, αγορά, φόρμες, ασφάλεια, 10.000 προϊόντα
```
Ο φάκελος `tests/` δεν περιλαμβάνεται στο πακέτο παραγωγής.

## 12. Δομή

```
index.php            front controller
cron.php             scheduler (CLI ή URL με κλειδί)
app/bootstrap.php    φόρτωση, χειρισμός σφαλμάτων, δρομολόγηση ανά domain
app/lib/             core, security, sanitize, platform, catalog, commerce, importer, feeds, seo, template, services
app/migrations/      σχήμα πλατφόρμας και καταστήματος (αυτόματα migrations)
app/routes/          superadmin.php, admin.php, store.php
app/views/           Super Admin, διαχείριση καταστήματος, κοινά (σελίδα κλειδώματος, σφάλματα)
app/templates/t01/   Bento Market (πρότυπο 01)
app/templates/t02/   Swiss Clarity (πρότυπο 02)
assets/              CSS/JS διαχείρισης και προτύπων
uploads/             εικόνες ανά κατάστημα (χωρίς εκτέλεση PHP)
data/                βάσεις, backups, logs, feeds (μη δημόσιο)
```
